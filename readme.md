-> Copy static, templates, requirement.txt, readme.md and app.py in a folder.

-> Type following command in the terminal to create virtual environment ``` python -m venv <environemnt name>```

-> Activate the environment ``` <environemnt name>\Scripts\activate```

-> Install all the library by typing in the terminal ```pip install -r requirement.txt```

-> After this run this in terminal ```python app.py```

-> copy the upcoming url and paste it in the browser.
